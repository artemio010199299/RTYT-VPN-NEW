# RTYT VPN — Android starter

This is a clean Android project starter for the RTYT VPN interface.

## Build APK using GitHub Actions
1. Upload the contents of this archive into the root of a new GitHub repository.
2. Open the **Actions** tab.
3. Run **Build RTYT VPN APK** (or push a commit to `main`).
4. Download the `RTYT-VPN-debug` artifact from a successful run.

## Important
This project currently contains only a basic preview screen and app icon. It does **not** implement a VPN service, tunnel, server connection, subscription parser, or traffic protection. Do not treat it as a working VPN.
